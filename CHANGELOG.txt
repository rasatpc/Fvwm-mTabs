FvwmTabs (Python 3) stable maintenance update

- Kept the Python socket/Tk architecture and preserved manual tabber/tabize behavior.
- Centralized command routing so socket commands and the internal dropdown use the same dispatcher.
- Added aliases for NewTabber, Tabize, NextTab, PrevTab, DestroyTabber, and quit.
- Restored compatible autoSwallowClass, autoSwallowResource, and autoSwallowName rules.
- Routed autoSwallow matches by internal numeric tabber ID and logged target existence/result.
- Kept successfully reparented windows tabbed when map, resize, raise, or focus commands only warn.
- Fixed WM_CLASS semantics: resource/instance is the first string, class is the second string.
- Added bounded autoSwallow retries, per-window pending/seen state, startup scan support, and skip logic for detectable transient/menu/dialog/override-redirect windows.
- Added structured X11 identity parsing and logging to ~/.fvwm/fvwmtabs.log.
- Fixed client-list polling to parse xprop WINDOW output and merge _NET_CLIENT_LIST with _NET_CLIENT_LIST_STACKING.
- Added INFO-level autoSwallow detection, identity, match, no-match, skip, and route logs for normal debug=false runs.
- Added a periodic fallback scan plus a one-time first-tabber safety scan for configured autoSwallow rules.
- Added the DumpAutoSwallow FVWM/socket diagnostic command.
- Made tab release use unmap/reparent/map so autoSwallowed client windows release like manually added windows.
- Added a kill fallback log/path for tabbed windows and made active tab styling clearer in both themes.
- Cleaned root-menu Add Window(s), Next Tab, and Previous Tab labels; selection cursor shape remains controlled by FVWM/xdotool/X11.
- Packaged the final polish release as FvwmTabs-v12-final-polish.zip.
- Added temporary autoSwallow suppression after manual tab release/destroy so matching windows are not immediately swallowed again.
- Added active-tabber tracking and active root-menu commands for Add Window(s), Next Tab, Previous Tab, and Destroy Tabber.
- Kept explicit tabber ID commands and default tabber 1 commands unchanged.
- Added practical code section comments for FVWM/Linux maintainers.
- Kept autoSwallowResource for compatibility because it is documented and matches the first WM_CLASS string.
- Documented that Add Window(s) picker cursor shape is controlled by FVWM/xdotool/X11.
- Packaged the final cleanup release as FvwmTabs-v12-final-clean.zip.
- Cleaned FVWM config and README instructions for the v12-stable architecture.
